## Escenario Seleccionado

Escenario B - Análisis de Ventas de una Pequeña Empresa.

## Descripción del Proyecto

El presente trabajo práctico tiene como objetivo aplicar conceptos de gestión colaborativa, control de versiones y organización empresarial mediante el uso de Jira, GitHub y Google Colab.

Se desarrolló un sistema simple de análisis de ventas utilizando Python. El programa procesa un conjunto de datos comerciales, calcula indicadores relevantes y genera resultados que permiten interpretar el desempeño de las ventas.

## Estructura del Repositorio

datos/

* ventas.csv

scripts/

* analisis_ventas.py

resultados/

* resumen_ventas.txt

## Indicadores Calculados

* Ventas totales.
* Producto más vendido.
* Ventas por mes.
* Generación de reporte automático.

## Tecnologías Utilizadas

* Jira
* Git
* GitHub
* Google Colab
* Python
* Pandas
* Matplotlib

## Ejecución

1. Clonar el repositorio.
2. Acceder al directorio del proyecto.
3. Ejecutar el script:

python scripts/analisis_ventas.py

4. Consultar los resultados generados dentro de la carpeta resultados.
